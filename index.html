Мечеть «Сабыр», Тюмень · время намаза, икама, джума, кибла

iPhone

Приложение открывается в Safari и ставится на экран «Домой» — работает без интернета.

Открыть приложение
  1. Откройте эту страницу в Safari и нажмите «Открыть приложение».
  2. Нажмите «Поделиться» (квадрат со стрелкой) → «На экран „Домой“».
  3. Напоминания о намазе — подпишитесь на календарь мечети (обновляется сам):
Подписаться на календарь намазов

Android

Приложение с уведомлениями, азаном, киблой и настройками для любого города.

Скачать приложение (APK) Открыть в браузере
  1. Скачайте файл и откройте его из «Загрузок».
  2. Если телефон спросит — разрешите установку из этого источника и нажмите «Установить».

Табло для мечети

Большое табло для телевизора: часы, отсчёт до азана и икамы, джума, бегущая строка.

Открыть табло Настройки табло APK для Android TV
  1. На телевизоре с Android TV поставьте APK — табло будет запускаться само при включении.
  2. Инструкция: установка на ТВ и телефон.
