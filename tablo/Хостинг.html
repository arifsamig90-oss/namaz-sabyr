Публикация «Намаз‑Табло» в интернете

Хостинг: как выложить сайт и получить ссылку · пошагово, без программирования · 30.09.2026
Коротко: чтобы сайт открывался по ссылке с любого телефона и телевизора, его нужно «выложить» (загрузить) на бесплатный статический хостинг. Ниже — готовые способы по шагам. Локальная версия (папка с файлами и «Запустить_сервер.bat») продолжает работать как раньше — интернет для неё не нужен.

Три вещи, которые важно понять сразу

  1. Сайт статический — подойдёт любой бесплатный статический хостинг: GitHub Pages, Netlify, Cloudflare Pages. Ни одна из страниц не требует сервера или базы данных.
  2. Настройки хранятся в браузере каждого устройства. «Изменять онлайн» = открывать /admin.html на сайте с любого устройства и настраивать под себя. Чтобы разослать свои настройки, в настройках есть кнопка «Скопировать ссылку с настройками» — получатель откроет сайт уже с вашей конфигурацией (сухур/чтение/икама/объявления и т.д.).
  3. Обновление сайта — загрузить файлы заново (2–3 клика). Все ссылки при этом остаются те же.

Способ 1. GitHub Pages — рекомендую (бесплатно и надёжно)

1
Зайдите на github.com и нажмите Sign up — зарегистрируйтесь (нужна почта; бесплатно, без карты). Если аккаунт уже есть — просто войдите.
2
Вверху справа нажмите «+» → New repository.
  • Repository name: namaz-tablo
  • Тип: Public
  • Нажмите Create repository. Галочки «Add README» ставить не нужно.
3
На странице репозитория выберите Add file → Upload files (или ссылку «uploading an existing file»).
4
Перетащите в окно браузера всё содержимое папки namaz-tablo: файлы index.html, admin.html, calendar.html, Установка.html, Хостинг.html, README.md и папку assets.
Важно: перетаскивайте файлы изнутри папки, чтобы index.html оказался в самом корне. Проще всего — заранее распаковать наш архив Намаз-Табло_для_хостинга.zip и загрузить его содержимое. Если загрузите лишние папки (data, screenshots) — не страшно.
5
Внизу страницы нажмите Commit changes и подождите, пока файлы загрузятся.
6
Откройте вкладку Settings → слева найдите Pages.
  • Source: Deploy from a branch
  • Branch: main, папка / (root) → Save
7
Подождите 1–3 минуты и обновите страницу — сверху появится ссылка вида
https://ваш-логин.github.io/namaz-tablo/
Это ваш сайт. Настройки: .../namaz-tablo/admin.html.
Обновление сайта (когда что-то поменяли в файлах): в репозитории снова Add file → Upload files → перетащите изменённые файлы → Commit changes. Через минуту-две сайт обновится.

Способ 2. Netlify — самый быстрый («перетащить папку»)

1
Откройте netlify.com и зарегистрируйтесь (бесплатно; можно войти через Google или почту).
2
Зайдите в раздел Sites → Add new site → Deploy manually — или сразу откройте app.netlify.com/drop.
3
Перетащите в окно браузера папку namaz-tablo целиком (или наш архив Намаз-Табло_для_хостинга.zip — Netlify сам его распакует).
4
Через полминуты появится ссылка вида https://krasivoe-imya-123.netlify.app. В Site settings → Change site name можно сделать её понятнее, например mechet-tyumen.netlify.app.
Примечание: у Netlify бывают ограничения бесплатного тарифа (лимиты трафика и «заморозка» неактивных сайтов). Для небольшого сайта мечети обычно хватает, но если попросят оплату — используйте GitHub Pages (Способ 1): там для таких сайтов лимитов практически нет.

Способ 3. Cloudflare Pages (для продвинутых)

  1. Аккаунт на dash.cloudflare.com (бесплатно).
  2. Workers & Pages → Create → Pages → Upload assets.
  3. Перетащите папку (или архив) → Deploy.
  4. Ссылка вида https://имя.pages.dev.

Способ 4. «Выложите сами — напишите мне в чат»

Если не хотите возиться: напишите в чат слово «выложи» и укажите email для аккаунта хостинга — я создам аккаунт на бесплатном сервисе surge.sh, загружу сайт и пришлю вам ссылку, логин и пароль (пароль потом можно сменить). Если у вас уже есть аккаунт на GitHub или Netlify — просто скажите, в каком сервисе выкладывать.

После публикации — чеклист

  • Откройте главную ссылку на телефоне — табло показывается; добавьте в закладки.
  • Откройте /admin.html и настройте под мечеть (название, икама, объявления).
  • Табло в мечети: откройте главную ссылку на приставке Android TV (как в «Установка.html»), полный экран, режим «киоска» — так сайт теперь не зависит от локального ПК.
  • Рассылка: просто отправляйте ссылку сайта; чтобы получатели видели ваши конкретные настройки — кнопка «Скопировать ссылку с настройками» в настройках.
  • Свой красивый адрес (необязательно): домен вроде mechet-tyumen.ru покупается отдельно (например, на reg.ru), подключается к GitHub Pages/Netlify за 10 минут — помогу, если нужно.

Частые вопросы

ВопросОтвет
Открывается белая страница или ошибка 404Проверьте, что index.html лежит в самом корне сайта и рядом есть папка assets. Подождите 1–3 минуты после публикации.
Ссылка из Способа 1 не открываетсяПосле включения Pages подождите пару минут и обновите страницу. Проверьте в Settings → Pages, что выбрана ветка main и папка / (root).
Как менять расписание онлайн?Открывайте /admin.html с телефона или компьютера. Изменения сохраняются на этом устройстве; для рассылки/переноса — «ссылка с настройками».
Хочу, чтобы правки сразу видели все посетителиДля этого нужен уже не статический сайт, а версия с общей базой (небольшой сервер/сервис). Это делается отдельным шагом — скажите, если нужно, обсудим варианты.
